# Progress

> "얼마나 찼나" 를 보이는 막대입니다. 예산 · 카드 한도처럼 쓸수록 차는 것과 저축 목표 · 카드 실적처럼 모을수록 차는 것에 씁니다. 이름 · 오른쪽 글 · 막대 · 금액 줄이 한 묶음입니다. 불러오기나 올리기 · 받기의 진행에는 쓰지 않고 [Progress Circle](progress-circle.md) 을 씁니다.

막대는 높이 하나(8) · 모서리 full · 색 하나(브랜드)이고, 넘친 한도만 위험 색으로 그립니다.

수치 원본은 [`progress.yaml`](progress.yaml)입니다.

## Properties

### 막대 — 높이 하나 · 색 하나

막대는 높이 8 · 모서리 full 이고, 트랙은 `bg-neutral-weak`, 채움은 브랜드 글자색(`fg-brand` — 다크는 밝은 짝)입니다. 화면의 요약 머리든 목록 줄이든 같습니다 — 크게 보일 것은 막대가 아니라 위의 금액(제목)입니다. 위에 이름(14 · 500)과 오른쪽 글(13)을, 아래에 금액 줄(12 · `fg-neutral-subtle`)을 두고 사이는 6 입니다.

이름과 오른쪽 글은 양 끝에 두고 사이는 적어도 8 입니다 — 이름이 길면 줄을 바꿔 오른쪽 글에 붙지 않게 합니다. 오른쪽 글(+ 사이 8)이 이름의 가장 긴 낱말 자리도 남기지 못하면(큰 글자 · 긴 금액) 오른쪽 글을 이름 아래 오른쪽 끝으로 내립니다. 차례는 이름 → 오른쪽 글 → 막대이고, 오른쪽 글은 자르지 않습니다. [List](list.md) 의 "큰 글자에서 값을 본문 아래로" 와 같은 방식입니다.

트랙이 페이지 바탕과 같은 색이라 막대는 흰 면(카드 · 시트) 위에 둡니다.

큰 글자에서 글(이름 · 오른쪽 글 · 금액 줄)은 두 플랫폼 모두 글자 크기 설정을 따릅니다. 막대는 웹이 rem 이라 배율대로 커지고(200% 에서 16), 앱은 8 그대로입니다 — 같은 설정에서 웹 막대가 앱보다 굵습니다. Chip 의 큰 글자 규칙과 같습니다.

### Meaning — 한도 · 목표

| 값 | 쓰는 곳 | 100% 를 넘으면 |
|---|---|---|
| `limit` *(기본)* | 예산 · 카드 한도(쓸수록 찬다) | 채움을 끝까지 + 위험 색(`fg-critical`) + 오른쪽 글 "N원 초과" |
| `goal` | 저축 목표 · 카드 실적(모을수록 찬다) | 끝까지 + 오른쪽 글 "달성" — 색은 그대로 |

[그림: 한도 · 목표 — 넘친 예산 · 달성한 실적](../../site/components/specs/progress.tsx#meanings)

### State

| 상태 | 모습 |
|---|---|
| `enabled` | 0 ~ 100% — 채움 브랜드, 오른쪽 글 비율("88%") |
| `over` | 한도를 넘음(`limit`) — 채움 끝까지 · 위험 색, 오른쪽 글 "20,000원 초과"(위험 색 · 700) |
| `reached` | 목표에 닿음(`goal`) — 채움 끝까지, 오른쪽 글 "달성"(본문 색 · 700). 색은 바꾸지 않음 |

## Guidelines

### 막대는 미터다 — 기다림에 쓰지 않는다

막대는 범위가 정해진 값이 얼마나 찼는지를 보입니다. 불러오는 동안 · 올리기 · 받기의 진행은 [Progress Circle](progress-circle.md) 로 보입니다(값을 모르면 도는 원, 알면 채우는 원). 값을 모른 채 흐르는 막대는 두지 않습니다.

[그림: 미터는 막대 · 진행은 원 — 올리기를 막대로 그린 화면](../../site/components/specs/progress.tsx#loading-guide)

### 두 값 견주기는 Chart — 비교 막대 줄

막대는 목표 · 한도에 얼마나 찼는지를 봅니다. "이번 달 | 막대 | 금액" · "지난 달 | 막대 | 금액" 처럼 두 기간의 합을 견주는 줄은 이 막대로 그리지 않습니다 — 트랙 위에 같은 색으로 채우면 지난 달이 "덜 찬 진행" 으로 읽히기 때문입니다. 그 줄은 [Chart](chart.md) 의 "두 값 견주기 — 비교 막대 줄" 입니다(트랙 없음 · 이번 `chart-blue` · 지난 `chart-blue-weak`). 이름 ↔ 오른쪽 글의 줄바꿈 규칙(위 "막대 — 높이 하나 · 색 하나")만 함께 씁니다.

### 넘친 한도 — 끝까지 + "N원 초과"

쓴 돈이 한도를 넘으면 채움을 끝까지 칠하고 위험 색으로 바꿉니다. 얼마나 넘었는지는 막대가 아니라 오른쪽 글이 말합니다 — "20,000원 초과". 막대를 100% 너머로 늘이거나 넘친 만큼 다른 색 조각을 잇지 않습니다.

[그림: 넘친 예산 — 끝까지 위험 색 + "20,000원 초과" · 넘친 만큼 이은 막대](../../site/components/specs/progress.tsx#over-guide)

### 목표에 닿으면 글자만

저축 · 실적이 목표에 닿으면 오른쪽 글을 "달성" 으로 바꿉니다 — 막대 색은 브랜드 그대로입니다. 성공 색 · 축하 모양을 더하지 않습니다. 넘어도(130%) 막대는 끝까지만 차고, 금액 줄이 실제 값을 보입니다.

[그림: 달성 — 글자만 · 초록으로 바꾼 막대](../../site/components/specs/progress.tsx#goal-guide)

### 주의 구간 색은 없다

한도에 가까워져도(85% 같은) 색을 바꾸지 않습니다 — 막대의 색은 브랜드 · 위험 둘뿐입니다. 가까워졌다는 알림은 사용자가 정한 예산 알림 기준이 알립니다.

### 글

- 이름은 무엇의 막대인지 — "식비 예산" · "여행 자금" · "현대카드 신용카드 전월 실적".
- 오른쪽 글은 반올림한 정수 비율 — "88%". 넘치면 "20,000원 초과", 닿으면 "달성". 마침표 없이.
- 금액 줄은 "현재 / 목표" — "350,000원 / 400,000원". 돈이 아닌 값은 그 단위로("6시간 / 8시간").
- 영어 · 코드값 · 카드사의 원색을 쓰지 않습니다.

## 코드

레시피 `recipes/shadcn/components/ui/progress.tsx` 를 씁니다. 아래 미리보기는 스펙 값으로 그린 모습입니다.

- `Progress` — 이름 줄 · 막대 · 금액 줄 한 묶음입니다. `label`(이름), `value`, `max`, `meaning`(`"limit"` 기본 · `"goal"`), `formatValue`(기본 `"350,000원"` 꼴 — 원 단위).
- `ProgressBar` — 막대만입니다(이름 · 글을 직접 그릴 때). `value` · `max` · `meaning` 과 이름(`aria-label`) · 값 글(`aria-valuetext`)을 꼭 줍니다.
- 막대는 `role="meter"` 입니다 — 진행(`progressbar`)과 나눕니다. 이름은 "{이름} {목표} 중 {현재}", 값 글은 오른쪽 글과 같은 말입니다. 보이는 이름 · 오른쪽 글 · 금액 줄은 같은 말을 두 번 읽지 않게 보조 기술에 숨깁니다.

### 예산 — 한도

[그림: 식비 예산 · 넘친 교통 예산](../../site/components/specs/progress.tsx#ex-limit)

```tsx
import { Progress } from "@/components/ui/progress"

<Progress label="식비 예산" value={350000} max={400000} />
{/* 넘치면 — 끝까지 위험 색, 오른쪽 "20,000원 초과" */}
<Progress label="교통 예산" value={120000} max={100000} />
```

### 저축 목표 · 카드 실적 — 목표

[그림: 여행 자금 · 달성한 카드 실적](../../site/components/specs/progress.tsx#ex-goal)

```tsx
<Progress meaning="goal" label="여행 자금" value={1200000} max={2000000} />
<Progress meaning="goal" label="현대카드 신용카드 전월 실적" value={390000} max={300000} />  {/* "달성" — 막대는 끝까지 */}

{/* 돈이 아닌 값 — 단위를 바꾼다 */}
<Progress meaning="goal" label="오늘 근무" value={6} max={8} formatValue={(h) => `${h}시간`} />
```

## Behavior

| 인터랙션 | 동작 |
|---|---|
| 값이 바뀜 | 채움이 300ms 로 따라 찹니다 — 처음 그릴 때는 움직이지 않습니다 |
| 한도를 넘음 | 채움 끝까지 · 위험 색, 오른쪽 글 "N원 초과" |
| 목표에 닿음 | 채움 끝까지, 오른쪽 글 "달성" — 색은 그대로 |
| 모션 줄이기 | 채움이 바로 바뀝니다 |
| 누르기 | 막대는 누르지 않습니다 — 줄 전체가 상세로 가면 [List](list.md) 줄이 맡습니다 |

## Accessibility

| 기준 | 검증 |
|---|---|
| **WCAG 1.4.3** Color contrast(글자 ≥ 4.5:1) | 이름 `fg-neutral` 흰 면 위 16.41 · 다크 13.42, 비율 · 금액 `fg-neutral-subtle` 5.50 · 6.09(떠 있는 면 5.27), "N원 초과" `fg-critical` 5.06 · 6.08 ✓ |
| **WCAG 1.4.4** Resize text | 이름 · 오른쪽 글 · 금액 줄이 글자 크기 설정을 따릅니다 ✓ — 막대는 웹 rem(배율대로) · 앱 8 그대로 |
| **WCAG 1.4.11** Non-text contrast(≥ 3:1) | 채움 : 트랙 Desk 7.76 · 다크 4.69, HR 7.56 · 4.67, 넘침 4.68 · 4.68 ✓. 트랙 : 바탕 1.08 · 1.30 — 장식(막대의 끝은 금액 줄이 말합니다) |
| **WCAG 1.4.1** Use of color | 넘침은 색과 함께 "N원 초과" 글, 달성은 글로만 ✓ |
| **WCAG 4.1.2** Name, Role, Value | `role="meter"` + 이름 "식비 예산 400,000원 중 350,000원" + `aria-valuemin` 0 · `aria-valuemax` 목표 · `aria-valuenow`(목표를 넘으면 목표) + `aria-valuetext`("88%" · "20,000원 초과" · "달성") ✓ |
| **WCAG 2.3.3** Animation from Interactions | 모션 줄이기면 채움이 바로 바뀝니다 ✓ |
| **WCAG 2.5.8** Target Size — Minimum(AA ≥ 24×24) | 누르는 것이 없습니다 — 해당 없음 |
| **WCAG 2.5.5** Target Size — Enhanced(AAA ≥ 44×44) | 누르는 것이 없습니다 — 해당 없음 |
| **ARIA** | 보이는 글(이름 · 오른쪽 글 · 금액 줄)은 `aria-hidden` 입니다 — 미터의 이름 · 값 글이 같은 말입니다. 미터를 모르는 보조 기술에서도 이름 · 값 글은 읽힙니다. 앱은 `Semantics(label: 이름, value: 값 글)` 입니다 |

## Do / Don't

### ✅ Do

- 막대는 하나, 높이 8 · 브랜드 채움으로 그립니다 — 요약 머리든 목록 줄이든 같습니다.
- 넘친 한도는 끝까지 + 위험 색 + "N원 초과" 로 보입니다.
- 목표에 닿으면 "달성" 글자만 바꿉니다.
- 보조 기술에는 미터로 읽힙니다 — "식비 예산 400,000원 중 350,000원".

### ❌ Don't

- 높이를 자리마다 다르게(6 · 7 · 10 · 12 · 16) 두지 않습니다.
- 주의 구간 주황 · 달성 초록 · 카드사 원색(장미 · 호박 · 초록)을 쓰지 않습니다.
- 다크에서 채움 색(`bg-brand-solid`)을 쓰지 않습니다 — 트랙에 묻힙니다(1.33:1).
- 불러오기 · 올리기 진행을 막대로 그리거나, 값을 모르는 흐르는 막대를 두지 않습니다.
- 넘친 만큼 막대를 더 그리지 않습니다.
- 두 기간을 견주는 막대 줄을 이 막대로 그리지 않습니다(Chart 의 비교 막대 줄).

## Specification

`progress.yaml` 의 규칙을 하나도 빼지 않고 조건마다 그립니다 — 웹 · 앱이 막대를 만들 때 이 값을 그대로 씁니다. 조건이 없는 `Base` 가 모든 조합에 걸리고, 뒤의 규칙이 앞의 같은 값을 덮습니다. 상태는 `enabled` 에서 바뀌는 값만 적습니다.
