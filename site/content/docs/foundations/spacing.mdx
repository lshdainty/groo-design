간격은 요소 사이의 공간으로 묶음과 흐름을 만듭니다. groo 는 2px 단위 눈금과, 자리마다 이름을 붙인 역할 간격을 씁니다.

## 목적

- **일관성** — 모든 화면과 컴포넌트가 같은 눈금을 씁니다.
- **모듈성** — 값 대신 이름(`spacing-x4`)으로 간격을 고릅니다. 값이 바뀌어도 부르는 자리는 그대로입니다.
- **가독성** — 여백으로 콘텐츠의 묶음과 흐름을 나눕니다.

## 역할 간격

자리에 이름을 붙인 간격입니다. 값은 아래 눈금 위에 있습니다.

- `spacing-global-gutter` 는 앱 · 768 미만 웹의 화면 좌우 여백입니다. 주간 띠 · 캘린더 격자 안 칸의 인셋 · 카테고리 탭 바의 전폭은 의도한 예외입니다.
- 웹에서 768 이상의 페이지 좌우 여백은 [Layout](/docs/foundations/layout) 의 `layout-margin` 입니다. 768 미만은 `spacing-global-gutter` 를 씁니다.
- 노치 · 홈 표시줄처럼 안전 영역이 있는 화면에서는 화면 끝이 아니라 **안전 영역 경계부터** 잽니다 — [Safe Area](/docs/foundations/safe-area).
