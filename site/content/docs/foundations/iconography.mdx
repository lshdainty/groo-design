아이콘은 복잡한 정보나 기능을 빠르게 알아보게 돕는 요소다. 뜻이 분명한 모양을 짧게, 어디서나 같은 굵기로 쓴다.

<Note>
  아직 제품에는 들어가지 않았다. 지금 제품에는 크기 18가지(8 ~ 48px)와 선 굵기 11가지가 섞여 있다 — 앱 적용 단계에서 아래 규칙으로 옮긴다.
</Note>

## 세트

<IconSetFigure />

groo 는 lucide 하나를 쓴다 — 웹은 `lucide-react`, 앱은 `lucide_icons_flutter`. 네 제품이 이미 이 세트다.

SEED 의 아이콘은 당근 로고의 모양을 딴 브랜드 자산이라 쓰지 않는다. 필요한 아이콘은 먼저 lucide 에서 찾고, 없으면 lucide 의 모양 규칙대로 그려 더한다.

## 크기

<IconSizeFigure />

<SourceTable heading="크기" />

- UI 아이콘은 세 단계만 쓴다. 지금 쓰는 다른 크기는 옮길 때 한 단계 위로 올린다.
- 바닥보다 작은 아이콘은 쓰지 않는다 — 작은 아이콘은 모양이 뭉개져 알아보기 어렵다.
- 빈 화면 · 큰 그림처럼 기본 격자보다 큰 아이콘은 격자를 비율대로 키워 자리마다 정한다.
- 자리마다 어느 단계를 쓸지는 컴포넌트 단계에서 SEED 의 해당 컴포넌트와 비교해 정한다.

## 선 굵기와 상태

<IconStateFigure />

SEED 는 켜짐 · 선택을 채움 아이콘으로, 꺼짐을 선 + 사선으로 보인다. lucide 에는 채움 모양이 없고, 앱의 lucide 글꼴은 채울 수도 없다. 그래서 groo 는 굵기와 색으로 대신한다.

- 기본은 lucide 의 선 굵기 그대로다. 선은 격자를 기준으로 그려져, 작은 아이콘에서는 그만큼 가늘어진다.
- 켜짐 · 선택은 진한 색(또는 브랜드 색)에 선을 굵게 한다.
- 꺼짐은 lucide 의 `-off` 아이콘(사선)을 쓴다 — 기능이 꺼지는 단추(알림 · 금액 가리기)만이다.
- 모으기 단추(관심 · 고정)는 꺼짐에 사선을 긋지 않는다 — 같은 아이콘이 흐린 색 + 기본 선, 진한 색 + 굵은 선으로만 갈린다. 채우지도 않는다.
- 켜고 끄는 단추의 아이콘은 누르면 할 일이 아니라 지금 상태를 그린다 — 금액을 가렸으면 `eye-off`. 이름은 그대로 두고 켬은 `aria-pressed` 가 알린다([Toggle](/docs/components/toggle)).
- 앱은 lucide 글꼴의 굵기 변형으로 같은 굵기를 맞춘다.

## 아이콘만 있는 버튼

<IconButtonFigure />

아이콘을 버튼으로 홀로 쓸 때는 읽기 쉽고 누르기 쉽게 넉넉한 자리를 둔다.

- 누르는 영역은 늘 [터치 영역](/docs/foundations/touch-targets) 기준 이상이다. 보이는 버튼이 그보다 작으면 보이지 않는 여백으로 채운다.
- 이름을 반드시 단다 — 웹은 `aria-label`, 앱은 `tooltip` 이나 `Semantics` label. 이름도 번역 문구에 둔다.
